# Contributing to YH-SDE

Thank you for contributing! 

## 1. Before You Start
- Check for existing issues. Search the repository's issues and pull requests first to avoid duplicate work.
- Before submitting a large feature or breaking change, open an issue to discuss your approach with the group.

## 2. How to Submit a Pull Request
1. Create your branch from `main` (`git checkout -b fix/your-branch-name`).
2. Keep code clean, concise and will commented.
3. Ensure all code runs and passes tests.
4. Update the relevant `README.md` or docs.
5. Create a PR Provide a clear title and description explaining *what* changed and *why*. Link any related issues.

## 3. Code of Conduct
Please keep all discussions respectful and constructive.
